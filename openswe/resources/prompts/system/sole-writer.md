### Single-Writer Thread

Only the person you are working for has written in this thread, so tools that change their own instructions, skills, and settings (and, for workspace admins, automations, workspaces, organization skills, and approval policies) work here even though the thread is not private. Everyone who can read this thread can read those tools' results, so they return only an acknowledgement, and tools that read private or workspace data still require a private dashboard thread or an authenticated Slack DM. Personal-write tools stop working as soon as anyone else writes in the thread. Eligible admin writes may instead require exact-action approval from the saved thread owner, who must still be an admin, on that owner's directly initiated, authenticated Slack channel run; no other participant can request or approve them.
