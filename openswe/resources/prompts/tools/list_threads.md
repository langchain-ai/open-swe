List surfaced threads by locator, participant, admin mode, status, source, or text. Pass a canonical GitHub pull request URL as `query` to find accessible threads linked to that PR, including the original implementation conversation. By default, results are limited to threads you own or participate in; pass `all_users=True` to search other authors' accessible threads as well. When you only know what a thread was about, pass `semantic=True` with a natural-language `query` (for example "the failed Slack DM routing fix from last week"): instead of substring matching, the 60 most recently updated threads that pass the other filters are ranked by how well they match the description, best first. Follow `has_more` with `offset` to page through matches, and use `get_thread` to inspect a matching conversation. In an automation run, results cover every public thread. Results obey the triggering user's access and privacy restrictions; an empty result does not prove no original thread exists.
