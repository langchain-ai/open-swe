List surfaced threads by locator, participant, admin mode, status, source, or text. Pass a canonical GitHub pull request URL as `query` to find accessible threads linked to that PR, including the original implementation conversation. By default, results are limited to threads you own or participate in; pass `all_users=True` to search other authors' accessible threads as well. Follow `has_more` with `offset` to page through matches, and use `get_thread` to inspect a matching conversation. Results obey the triggering user's access and privacy restrictions; an empty result does not prove no original thread exists.
