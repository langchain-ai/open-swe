Run one SQL statement against the Open SWE application database, writes included, on a preview or staging deployment only.

This tool is available only to admins on a private admin surface: a private dashboard thread or authenticated Slack DM. The statement runs in its own transaction, which commits when it succeeds and times out after 60 seconds. Use it to repair what the narrower tools cannot reach, such as migration metadata in `alembic_version`, and use `read_only_sql` for anything that only reads. Pass `confirm=true` only after showing the requester the exact statement and getting their approval. Tables live in the deployment's schema, so qualify them (for example `open_swe.alembic_version`). A statement that returns rows answers with `columns` plus positional row arrays, limited to 1,000 rows and 1 MB; any other statement answers with the affected `row_count`.
