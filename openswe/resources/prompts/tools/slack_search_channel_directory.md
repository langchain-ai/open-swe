Search the cached Slack channel directory by name, purpose, or topic to find places to ask a question.
No Slack search grant is needed.
Up to 20 distinct words match any term; name matches rank higher, then member count breaks ties.
Returns channel IDs, names, purposes, topics, and member counts for listed public, unarchived, internal channels only, based on cached metadata.
Results are limited to 25.
Use `#channel-name` when suggesting a channel to a person.
