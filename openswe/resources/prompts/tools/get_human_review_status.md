Report where a pull request's review request stands and who it is assigned to: its kind, state and latest detail, the thread that requested it, who requested it, reviewers who accepted, pending picks with when they must accept by and any snooze, people released after declining or not accepting, GitHub approvals, and each code owner area of the changed files with who is assigned to and who approved it. Use it to answer "who is reviewing this?", "who is this assigned to?", or "why was I removed?" before answering from memory, since assignments change while you are not running.

Pass `review_request_id` to read one request in any state, such as the one a `<replying_to>` notice names. Otherwise pass `pr_url` to read the pull request's open request; `open_review_request` is false when it has none.
