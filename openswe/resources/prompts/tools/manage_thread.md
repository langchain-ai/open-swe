Manage a Robin thread without deleting it.
Use rename with title to change a thread's title, including this thread, in cloud or desktop.
This preserves the chosen title against automatic retitling; no browser login or manual API request is needed.
Use resolve/unresolve to close or reopen it, and cancel to stop a run.
Use mark_read/mark_unread to change only the requesting person's read state, not anyone else's.
