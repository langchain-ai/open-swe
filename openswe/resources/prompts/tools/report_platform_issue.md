Report an issue with the sandbox or execution environment.
Requires a problem description. Reports are saved as admin-only `platform_issue` events and sent to the workspace's memory curator explicitly as problem reports, not memories. Private-thread contents and diagnostics are withheld from the public curator thread; it receives only a notice.
Check `event_log_status` for persistence, `curator_status` for forwarding, and `export_status` for feedback on this thread's LangSmith trace. A failed destination does not prevent delivery to the others.
