Follow a thread's conversation until it finishes, like `gh run watch` or `tail -f`. Accepts the same locators as `get_thread`. Each call waits up to `wait_seconds` (at most 30) and returns as soon as the thread has new user or assistant messages, its run stops, or the wait ends. The first call, without `cursor`, returns the latest messages; pass each response's `cursor` to the next call to receive only what came after it. Keep calling until `done` is true: the thread is no longer running and every message was returned. `status` then says how it ended (`finished`, `error`, `interrupted`, or `idle`). `has_more` means the response hit its size limit and the next call returns the rest at once; `cursor_reset` means the earlier cursor no longer exists and the messages restart from the latest ones.
