List Robin's repository and Slack channel integration bindings.
Requires an authorized admin thread.
Bindings are global integration configuration, not execution environments, sandbox access grants, or image preloads.
Slack entries list listening channels with their `channel_id` and editable `prompt` instructions.
Channel rules list each name `prefix` with its listening `prompt` and optional `kickoff` instructions; every public internal channel named with a prefix listens with that prompt.
