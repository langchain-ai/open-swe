Inspect a thread from its ID, dashboard/Slack/LangSmith URL, or LangSmith run ID. `transcript.messages` holds the newest `limit` (default 50, max 100) user and assistant messages, oldest first. To read further back, pass `transcript.next_before` as `before`; it is null once nothing older matches. `query` keeps only messages containing that text, case-insensitively. `include_tools=True` adds each assistant message's `tool_calls` (name and JSON args) and `tool_result` entries (tool name and content); long text is truncated.
