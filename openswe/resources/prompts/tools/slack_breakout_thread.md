This is only for requested breakouts, not a general mechanism for creating Slack threads. Breakouts only work in public channels. Omit `channel_id` to use the current channel. Set `web_only=true` only when the user explicitly asks for a web breakout (the equivalent of `/breakout:web`). Never choose a web breakout proactively or merely because a question seems quick. It creates a private, web-only conversation seeded with the full Slack transcript, with no Slack attachment or destination; omit `channel_id`. Share the returned `dashboard_url` with the requester. The Slack completion instructions below apply only when `web_only=false`.

When called from a Slack thread, post nothing in that thread before this call. On success the tool marks the request with a reaction itself, so end the turn with `slack_no_reply_needed`; on failure, tell the asker why. From a Slack slash-command run, share the returned `slack_url` and `dashboard_url` with the asker.
