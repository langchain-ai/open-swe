Move an Open SWE thread to a local Claude Code session: its conversation becomes a new Claude Code session on this machine that continues the work, resumed with `claude --resume <session_id>`. The thread itself is unchanged and keeps working on its own.

Pass the thread as `thread_id` (a thread ID or Open SWE dashboard URL) and the absolute path of the local clone of the thread's repository as `cwd`; the new session belongs to that directory. The tool returns the new `session_id`, the `transcript_path` to write it to, the `repo`, `branch` and `pr_url` the thread pushed its work to, a `download_url`, a one-time `download_token` valid for `expires_in_seconds`, and `next_step`.

Downloading takes more than this call, because the transcript has to land in a file on this machine. Follow `next_step`: fetch the gzipped transcript from `download_url` with `Authorization: Bearer <download_token>` into `transcript_path`, check out `branch` in `cwd`, then tell the user to run `claude --resume <session_id>` from `cwd`. Only work the thread pushed carries over; if it has unpushed changes, ask it to push first. `download_token` is a credential, so keep it out of anything you post.
