# Robin mobile

An Expo (React Native) iOS app.
See [README.md](README.md) for how to run it and how it talks to the backend.

## Expo has changed — do not trust your training data

Expo ships breaking changes every SDK release.
Before writing code that touches an Expo or React Native API:

1. Read the major version of the `expo` package in `package.json`.
2. Read the matching versioned docs: `https://docs.expo.dev/versions/v<major>.0.0/`
3. For anything else, start from https://docs.expo.dev/llms.txt and follow its links to the page you need.

## Commands

```bash
npx expo install <package>  # adds SDK-compatible versions through pnpm
pnpm ios                    # development build in a simulator, plus Metro
pnpm typecheck
```

Lint and formatting run from the `open-swe` root: `pnpm run lint` and `pnpm run format:check`.

## Rules

- The product is called Robin in anything a person sees.
  Identifiers keep their Open SWE names (bundle ID, the `openswe://` scheme, the Keychain item, the `open-swe-auth` module), so existing installs keep working.
- Routes live in `src/app/`; every file there is a screen and `_layout.tsx` files define navigators.
  Keep everything else outside `src/app/`.
- `ios/` is generated by `expo prebuild` and ignored.
  Configure native behavior in `app.json`, config plugins, or the local module in `modules/`.
- Prefer native UI: Expo Router's stack toolbar, menus and sheets, and `@expo/ui` SwiftUI controls, over JavaScript lookalikes.
- Use the semantic tokens in `src/design/theme.ts` for colors.
  Native header and toolbar tints need plain colors, so use `useHeaderTint` there.
- Adding a library with native code needs a new development build.
