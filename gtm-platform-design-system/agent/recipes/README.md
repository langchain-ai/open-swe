# Recipes

A recipe is the order the decisions get made in, not a snippet to paste. The
components are documented in `../CATALOG.md`; what these add is which question
you answer first, because that ordering is where surfaces drift apart.

Before any of them, state six things in a sentence each. If you cannot, the
component choice is premature:

1. The one decision the user takes on this surface.
2. The dominant region, and how the others yield to it.
3. The live endpoint fields you actually have.
4. The page archetype (`PageFrame`, a masthead route, or a shell pane).
5. The containment ledger: every visible edge names a bounded action region.
6. The owner of every control: it belongs beside the smallest region it changes.

- [an-agent-surface.md](an-agent-surface.md) — a thread, its rail, and the work beside it
