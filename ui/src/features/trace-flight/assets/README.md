The Bufo cameos come from [all-the-bufo](https://github.com/knobiknows/all-the-bufo).
That repository has no license, so these files are **not** covered by this repository's MIT license.

- **Permission:** granted by the Trace Flight project owner (OPE-134) on 2026-11-10, for use in the game: in this repository's source, the web app and the desktop app.
- **Changes:** each image is converted to grayscale, and animated GIFs are laid out as horizontal sprite sheets.
  Frame timing lives in `view/bufos.ts`.
