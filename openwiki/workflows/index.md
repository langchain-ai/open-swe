# Files

- [Run Context Engineering Workflow](context-engineering.md) - How Open SWE renders inbound conversation data, identities, attachments, repository rules, dynamic context, prompt scopes, and virtual skills into a safe, durable agent run. Covers provenance, lifecycle, precedence, and bounded context-loading behavior.
- [Follow-up, Interrupt, and Stop Workflow](follow-up-messages.md) - Explains how follow-up input is bound to an existing thread, when a new run interrupts versus waits, how dashboard messages enter the store-backed queue, and how Slack and dashboard stops affect work.
- [Inbound Invocation Workflow](invocation.md) - How dashboard, GitHub, Slack, Linear, desktop, and scheduled automation requests are authenticated or authorized, resolved into threads and structured input, dispatched durably, and reported on completion.
- [Pull Request Delivery Workflow](pr-creation.md) - How an agent pushes changes, creates or updates an attributed GitHub pull request, and exposes CI and review feedback. Covers delivery guards for direct PR creation and GitHub Actions workflow changes.
- [Pull Request Review Workflow](pr-review.md) - How Open SWE turns GitHub pull-request events and requests into a bounded, read-only reviewer run, durable findings, GitHub review comments, and re-review reconciliation.
- [Scheduling, Background Work, and CI Monitoring](scheduling-and-baby-sit.md) - How deterministic scheduler ticks launch recurring automations, one-shot wakeups, cost refreshes, reconciliation, and sandbox monitoring. It also explains durable /baby-sit PR watches, signed GitHub CI events, and bounded flaky-CI handling.
