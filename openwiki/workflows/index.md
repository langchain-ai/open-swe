# Files

- [Context Assembly and Prompt Engineering](context-engineering.md) - How Open SWE converts external events into safe, attributed model input and assembles per-run system context from prompts, repository rules, workspace settings, source guidance, and skills.
- [Follow-Ups, Interrupts, and Completion Replies](follow-up-messages.md) - How Open SWE delivers new work to an active thread through durable runs or a persistent message queue, and how stops, completion callbacks, and background tasks settle that work.
- [Human and Expedited Review](human-review.md) - Slack-centered lifecycle for standard GitHub review requests and expedited diff approvals, including routing, reviewer selection, deadlines, closure, and merge safeguards.
- [Incident Response Workflow](incidents.md) - How Open SWE enrolls eligible Slack channels as incidents, captures and analyzes channel evidence in protected system-owned turns, coordinates responders, and persists evidence-backed reports and postmortems.
- [Inbound Invocation and Durable Dispatch](invocation.md) - How signed GitHub, Linear, and Slack callbacks, authenticated dashboard commands, and scheduled automations become attributed inputs, routed threads, durable LangGraph runs, and completion work.
- [Implementation and Pull Request Creation](pr-creation.md) - How an Open SWE agent turns sandbox changes into an attributed GitHub pull request, with guarded workflow pushes, human approval, PR recording, and CI or review follow-up.
- [Pull Request Review Lifecycle](pr-review.md) - How Open SWE admits GitHub pull-request reviews, prepares reviewer and scout runs, persists and publishes diff-grounded findings, and reconciles later pushes and human feedback.
- [Scheduling, Monitoring, and Baby-Sit](scheduling-and-baby-sit.md) - How the PostgreSQL job queue runs recurring and delayed maintenance, wakes threads, reconciles stuck runs, refreshes costs, monitors background commands, and watches pull-request CI.
- [Task and Worker Coordination](task-coordination.md) - Explains how Open SWE durably delegates work from a coordinator thread to worker threads, authorizes their shared task, exchanges queued task events, and handles launch failures, completion, retry, cancellation, workspace, model, and sandbox inheritance.
