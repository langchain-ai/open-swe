Assign work asynchronously to an Open SWE worker thread with its own conversation and checkpoints. On first delegation, creates a task record and makes this conversation its coordinator; later delegations and retries reuse that task. No separate setup or acceptance criteria are required to spawn. Task-level criteria can be recorded with assess_task and are separate from worker assignment instructions. Returns its thread reference without waiting for the work to finish. Optionally choose a model and supported reasoning effort at runtime; otherwise inherit the coordinator's choice or workspace default. Workers share the coordinator's sandbox: assign disjoint files and coordinate checkouts, branch changes, integration edits, and tests. After the first delegation, keep implementation delegated and handle user communication here. Workers must ask their coordinator for additional workers instead of delegating. A failed launch returns the reserved worker identity; retry it with control_worker rather than spawning a replacement. Completion and failure results are automatically delivered to the coordinator; assess_task decides task completion, not a worker finishing.
