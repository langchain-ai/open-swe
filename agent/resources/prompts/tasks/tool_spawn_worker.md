Assign work asynchronously to an Open SWE worker thread with its own conversation and checkpoints. On first delegation, creates a task record and makes this conversation its coordinator; later delegations and retries reuse that task. No separate task-record setup is required. Returns its thread reference without waiting for the work to finish. Optionally choose a model and supported reasoning effort at runtime; otherwise inherit the coordinator's choice or workspace default. Workers share the coordinator's sandbox. Resolve repository/setup requirements before concurrent inspection begins; include known checkout state, freshness limitations, read-only constraints, and any requested progress checkpoint in each assignment. Do not refresh or mutate a read-only checkout to satisfy general setup guidance. Assign disjoint files for edits and coordinate any authorized shared-state change with every affected worker before proceeding. Prefer delegating substantial work to stay available for user communication; handle small edits, focused checks, and follow-ups directly when delegation would add more overhead than value, coordinating with active workers first. Workers must ask their coordinator for additional workers instead of delegating. A failed launch returns the reserved worker identity; retry it with control_worker rather than spawning a replacement. Completion and failure results are automatically delivered to the coordinator. Evaluate the combined results in the conversation rather than treating a worker finishing as proof that the user's request is satisfied.
