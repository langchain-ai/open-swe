Update the account mapping for an existing Open SWE GitHub user and a verified Slack member ID. Only workspace admins can use this tool. Obtain the exact Slack ID (for example with `slack_lookup_github_user`) and GitHub login; never guess based on a similar name. This moves a previously linked Slack identity to the requested GitHub account. Tell the requester about any previous owner before making a disputed or surprising reassignment. Do not use this for self-service OAuth linking; users can link their own accounts through Profile Settings.
