Open a new Slack code channel in which a review guide walks the person asking through a pull request, a small chunk at a time, answering their questions as they go and approving it on GitHub when they ask.

Use it when someone asks to be walked through, guided through, or taken through the review of a pull request. It opens its own session; this thread stays as it is.

- `pr_url`: the pull request, as `https://github.com/<owner>/<repo>/pull/<number>`.
- `invite`: anyone else to add to the channel, as Slack user ids. The person asking is always added.

Reply with the channel link from the result.
