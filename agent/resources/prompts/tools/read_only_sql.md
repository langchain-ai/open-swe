Run one PostgreSQL query against the Open SWE application database.

This tool is available only in an admin's private dashboard thread. The database transaction is enforced as read-only and times out after 10 seconds. Submit exactly one query. Results are returned as `columns` plus positional row arrays and limited to 100 rows and 100 KB, so aggregate and filter narrowly. Never use it to retrieve secrets, credentials, tokens, message content, or other sensitive data unless the user explicitly requests the specific data and is authorized to receive it.
