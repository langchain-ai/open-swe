Run one PostgreSQL query against the Open SWE application database.

This tool is available only on a private admin surface: a private dashboard thread or authenticated Slack DM. The database transaction is enforced as read-only and times out after 60 seconds. Submit exactly one query. Results are returned as `columns` plus positional row arrays and limited to 1,000 rows and 1 MB, so aggregate and filter narrowly. Never use it to retrieve secrets, credentials, tokens, message content, or other sensitive data unless the user explicitly requests the specific data and is authorized to receive it.
