Break out a separate task using the same feature as `/breakout`, with a headline root and self-contained instructions as the first reply. This is only for requested breakouts, not a general mechanism for creating Slack threads. Breakouts only work in public channels. Omit `channel_id` to use the current channel. Pass `channel_id` only when the user explicitly chooses a destination. The current conversation remains active; to move the current conversation and stop listening to the original thread, use `slack_move_thread` instead.

When called from a Slack thread, post nothing in that thread before this call. On success the tool marks the request with a reaction itself, so end the turn with `slack_no_reply_needed`; on failure, tell the asker why. From a Slack slash-command run, share the returned `slack_url` and `dashboard_url` with the asker.
