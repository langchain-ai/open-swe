Inspect a thread from its ID, dashboard/Slack/LangSmith URL, or LangSmith run ID. The transcript includes user and assistant text, structured reasoning, and tool-only assistant entries rendered as compact tool-call placeholders; system and tool-result messages are counted as non-conversational. Use `transcript_offset` with the returned `next_offset` while `has_more` is true to fetch later conversational messages. `unreadable_count` counts conversational entries without readable text or tool calls, `per_message_clipped_count` and `aggregate_clipped_count` describe returned text clipping, and `truncated` only indicates another page exists.
