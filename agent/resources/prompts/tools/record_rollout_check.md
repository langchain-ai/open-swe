Store this thread's rollout check before or when you open a pull request. Pass `owner`, `repo`, and `environments`. Determine `environments` from this repository: the deploy targets a merged commit reaches, earliest first. Look through its deployment configuration and Datadog configuration for each target's tags and for the UI host of that environment. Each item has `name`, `targets`, `datadog_tags`, and `host`. `targets` are ids the rollout locate tool returns. Group targets that ship as one revision. Use only targets, tags, and hosts you found. The server watches only repositories configured for rollouts, and only the environments recorded here. Pass `page` and `expected` when the change is visible. Pass `metrics` when the diff can move latency or system metrics. Leave `environments` empty when this change has no deploy targets to watch.
