Delegate an assignment to a new ordinary Open SWE worker thread and return immediately without waiting for its result. Set task acceptance criteria first. Optionally choose a supported model and effort; instructions define the assignment. The worker has independent conversation checkpoints and lifecycle but shares this task's sandbox. Avoid overlapping writes and coordinate shared files explicitly.

Only the permanent coordinator may spawn workers. The first delegation permanently ends the coordinator's implementation permissions: delegate all later edits, integration, conflict resolution, and tests, even after workers finish. Existing background shell commands must finish or be explicitly stopped before delegation. Workers cannot spawn other workers or synchronous subagents; they request help through report_worker_progress.
