Save feedback explicitly provided by the user about a published Open SWE review assessment.

Use the GitHub review ID of the assessment the user is rating. Submit `helpful` or `unhelpful` and their optional comment; never infer or invent a rating. This replaces only the authenticated user's feedback for that assessment. It does not post to GitHub, change approval policy, or approve the PR. Available only to the authenticated owner of a private task with access to the repository.
